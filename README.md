# NotebookLM Source Cleaner

为 Google NotebookLM 来源列表提供批量选择与一键删除能力的 Chrome 扩展。

## 功能
- 批量选择来源
- 一键删除选中项
- 删除进度提示
- 路由切换后自动恢复工具栏

## 适合谁
- 高频使用 NotebookLM 的内容、研究、产品用户
- 经常需要清理大量来源的用户

## 安装方法
1. 打开 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目目录
5. 打开 `https://notebooklm.google.com`

## 使用方法
1. 在来源列表点击“批量选择”
2. 勾选要删除的来源
3. 点击“删除选中”
4. 等待进度提示结束

## 已知边界
- NotebookLM 是动态 SPA，若官方更新 DOM 结构，选择器可能需要同步更新。
- 如遇工具栏不显示，刷新页面后重试。
